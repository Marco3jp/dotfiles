## 作業の進め方

### ツールがタイムアウトしたら止まって声をかける

承認ダイアログが出るツールは、承認が間に合わないだけでタイムアウトすることが多い。タイムアウトを見たら、リトライも別の経路探しもせず「承認が間に合わなかったかもしれないので、再開していいか」と聞いて待つ。クエリを軽く書き直したり、認証情報や別のデータソースを探しに行ったりしない。接続そのものを疑うのは、ユーザーが接続断だと言ったときだけ。

### メモリのインデックスは短く保つ

MEMORY.md は毎セッション読み込まれるので、1行は「タイトル＋読みに行くか決められる短いフック」だけにする（目安80〜120バイト）。実値・パス・手順は個別ファイルに書く。

月1回くらいで見直す。

1. インデックスと実ファイルを突き合わせる。行が無いメモリは思い出されない
2. project タイプで案件が終わったものは消すか、要点だけ reference に縮める
3. 90日更新されていないファイルは、中身が今も正しいか見る
